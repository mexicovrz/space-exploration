## 📖 О игре

**Space Exploration** — это 2D-симулятор космического пилота с видом сверху.  
Ты играешь за выжившего после крушения корабля. Твой прыжковый двигатель уничтожен, а галактика вокруг — незнакомая и опасная.

**Твоя цель:** зарабатывать деньги, находить детали, чинить корабль и в итоге вернуться домой.

**Основные механики:**
- Полёты между станциями и секторами.
- Торговля: покупай дёшево, продавай дорого.
- Ремонт корабля: меняй изношенные детали на новые.
- Апгрейды: ставь MK2-детали для бонусов.
- Бой: сражайся с пиратами или убегай.
- Сюжет: 4 квеста в цепочке с диалогами NPC.
- Исследование: 20 процедурно-сгенерированных секторов.

## 📦 Установка (Android APK)

Игра распространяется как **APK-файл** — устанавливается в один клик, как обычное приложение.

### Как установить

1. Перейди в раздел **Releases** этого репозитория.
2. Скачай последний файл `space-exploration-vX.X.X.apk`.
3. На устройстве открой **Настройки → Безопасность → Установка неизвестных приложений**.
4. Разреши установку для **браузера** (или файлового менеджера), через который будешь открывать APK.
5. Открой скачанный APK → нажми **Установить**.
6. Готово! Значок игры появится на рабочем столе.

> ⚠️ **Внимание:** Android может показать предупреждение «Приложение из неизвестного источника». Это нормально для APK, которые не из Google Play. Нажми **«Всё равно установить»**.

### Требования

- **Android 7.0** (API 24) или выше.
- **~150 МБ** свободного места.
- **Планшет или телефон** — игра адаптируется под любой размер экрана.
- **Ориентация:** горизонтальная (landscape).

### Как обновить игру

1. Скачай новый APK из Releases.
2. Открой его поверх старой версии — Android сам обновит.
3. Прогресс в игре **сохранится** (сейв лежит в `saves/save.json`).

### Как удалить

Как обычное приложение: долгий тап по значку → **Удалить**.

⚠️ **Сохранение** удалится вместе с приложением. Если хочешь сохранить прогресс — скопируй папку `saves/` из внутренней памяти.

## 🎮 Как играть

### Основное управление

Всё управление — **пальцем по экрану**, кнопок для запоминания минимум.

| Действие | Как сделать |
|----------|-------------|
| **Задать курс** | Тап по любому месту карты |
| **Выбрать цель (NPC)** | Тап по чужому кораблю |
| **Стыковка со станцией** | Тап по станции вблизи |
| **Прыжок через врата** | Тап по вратам вблизи |
| **Открыть меню станции** | Стыковка → тап по кнопкам |
| **Пауза** | Кнопка **II** внизу |
| **Ускорение времени** | Кнопка **x1 → x2 → x5** |
| **Остановить корабль** | Кнопка **STOP** |
| **Ремонт** | Кнопка **РЕМОНТ** |
| **Контракты** | Кнопка **КОНТР.** |
| **Карта галактики** | Кнопка **КАРТА** |
| **Инвентарь** | Кнопка **ИНВ.** |
| **Сохранить игру** | Кнопка **СОХР.** вверху справа |

### Как понять, куда лететь

- **Мини-карта** в правом нижнем углу — показывает твой сектор целиком.
- **Метки на станциях:**
  - **«!»** — здесь доступен сюжетный квест.
  - **«СЮЖЕТ»** — доставь груз сюда.
  - **«КОНТР»** — сдай контракт.
- **Карта галактики** — открывается кнопкой **КАРТА**, показывает все открытые сектора и связи между ними.

### Как заработать первые деньги

1. Стыкуйся к станции → **«Контракты»** → возьми доставку.
2. Доставь груз → получишь оплату.
3. Или атакуй **пирата** (красный корабль) → обломки → подбери лут → продай в магазине.
4. Или продай ненужные детали на станции.

### Что делать, если сломался

- **Открой РЕМОНТ** → выбери систему → тапни слот → **«Поставить из трюма»**.
- Если нет подходящей детали — купи в магазине.
- Если **корпус сломан полностью** — ты умрёшь. Не подставляйся под огонь.

## 🚀 Что в игре (полный список механик)

### Корабль

- **6 систем:** двигатель, реактор, O2-генератор, корпус, оружие, щит.
- **3 слота** в каждой системе — ставь разные детали.
- **Износ:** каждая деталь со временем теряет HP.
- **MK2-детали** дают бонусы: скорость, экономия топлива, +HP и т.д.
- **3 типа корабля:**
  - **Скиталец** — сбалансированный, стартовый.
  - **Тягач** — большой трюм (150), но медленный.
  - **Курьер** — быстрый, экономичный, маленький трюм (50).

### Экономика

- **Магазин деталей:** купить / продать.
- **Продажа по износу:** новая деталь = 100% цены, изношенная = меньше.
- **Хлам и трофеи:** продаются оптом одной кнопкой.
- **Контракты:** доставка груза между станциями за деньги.
- **Верфь:** покупка нового корабля.

### Бой

- **Хитскан-оружие:** тапнул по врагу → автострельба, если в радиусе.
- **Щит:** поглощает урон первым, восстанавливается со временем.
- **Корпус:** HP системы, зависит от деталей.
- **Лут:** с пиратов падает хлам, трофеи (золото, камни, артефакты), иногда — детали.
- **Розыск:** убил мирного NPC → патрули атакуют без предупреждения.

### NPC

- **Торговцы** — нейтральные, летают между станциями.
- **Доставщики** — быстрые, мирные.
- **Патрули** — сильные, охраняют порядок.
- **Пираты** — атакуют игрока и патрули.

### Сигналы бедствия

- Появляются **только если у тебя есть сканер** (деталь в корпусе).
- 5 типов: обломки, засада, торговец, тайник, пустой сигнал.
- Живут **5 минут**, потом исчезают.

### Галактика

- **20 секторов**, процедурно-сгенерированных.
- **Врата** в 4 углах каждого сектора — прыжок за деньги и топливо.
- **Карта галактики:** видны только посещённые сектора и их соседи.
- **Сохранение:** прогресс по всем секторам хранится в сейве.
